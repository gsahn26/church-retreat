# 쉼의 교회 (Church of Rest)

지친 마음이 잠시 쉬어가는 3D 디지털 묵상 공간입니다. [Silent Chapel](https://silent-chapel-2igk.vercel.app/)에서
영감을 받은 개신교(교회) 버전으로, React Three Fiber로 만든 걷기 가능한 예배당 공간과
QT(묵상 기도) 기능을 제공합니다.

## 주요 기능

- **3D 교회 공간**: WASD 이동 + 마우스 시점으로 교회 정원 · 본당 · 묵상실을 자유롭게 둘러볼 수 있어요.
- **묵상 기도(QT)**: 본당 제단 앞에서 `E`를 누르거나 상단 "묵상 기도" 버튼으로 시작. 감사·회개·중보·치유
  네 가지 주제 중 하나를 골라 단계별 기도문으로 묵상을 진행합니다.
- **캐릭터 꾸미기**: 옷차림과 머리 스타일을 선택할 수 있어요.
- **한국어 / English** 2개 언어 지원.

이 공간은 실제 예배나 목회 상담을 대신하지 않는 개인 묵상 도구입니다.

## 시작하기

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) 에서 확인하세요.

## 빌드

```bash
npm run build
```
